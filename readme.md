
# JetBus

JetBus adalah aplikasi berbasis web untuk melakukan pemesanan tiket bus. Project ini dibuat menggunakan PHP Native dan MySQL sebagai bagian dari pengembangan aplikasi berbasis web serta kelengkapan tugas matakuliah pemrograman web dasar.

JetBus menggunakan Midtrans untuk mengintegrasikan proses pembayaran pada sistem.

Integrasi yang diterapkan masih berada pada tahap sandbox, sehingga transaksi yang dilakukan hanya berupa simulasi dan tidak menggunakan pembayaran secara nyata.

## Teknologi
- PHP Native
- MySQL
- HTML & CSS
- JavaScript
- Bootstrap
- Midtrans
- XAMPP


## Cara Menjalankan


1. Clone repository

```bash
https://github.com/mulkirhmn/jetbus.git
```

2. Pindahkan folder project ke:

```bash
c:\xampp\htdocs\
```

3. Jalankan Apache & MySQL

4. Buat database MySQL dan import file:

```bash
jetbus.sql
```
6. Jalankan aplikasi melalui browser:
```bash
http://localhost/jetbus
```
